# Explore layout release build recovery

The approved UI feature is local commit 7866708deefe1d72e10ffdccc1c912cbc13fdf09, based on canonical main 7cf992cfb070b1edf6dc739355a5532e352787b6. Fresh Sites source is public version 334, mirror 9b06fc437075f04620f661f5d5aaa8045b67ba61. The mirror's tracked production files match current canonical main byte-for-byte. Original checkout and four stashes are preserved.

The old build serializes every artwork byte into a roughly 298 MB intermediate Worker, writes it, then evaluates that same asset table in a VM before replacing it with the approximately 64 MB lazy Worker. Holding the original table and its parsed copy caused heap/swap pressure; writing the intermediate alongside client/native outputs exhausted available disk.

The build now supplies its already prepared asset table to splitWorker and passes the existing asset-free device engine as the input source. No full artwork Worker is materialized or written. The optimizer streams the equivalent JSON entries into its SHA-256 and byte-count calculation, keeping the identical immutable pack prefix and diagnostic input size. It replaces the asset declaration by its explicit boundary, avoiding another full serialization. Mobile output continues to use the same prepared asset table and engine. Runtime handlers, CSP, image privacy checks, offline data and asset bytes are unchanged.

check-prepared-assets.mjs compares the legacy and prepared inputs in both compressed and static modes. It asserts exact Worker, complete manifest, pack prefix and every emitted file byte; then exact API, Unicode text, all 256 binary byte values, release, sync-guard and missing-route responses. It also verifies that the input table is unchanged. The check is part of check:release.

History-preserving Git compaction could not complete within available disk, including a bounded-memory retry. Both failed temporary packs were removed only after termination; source refs remain identical (SHA-256 of show-ref: 2a1a4ab2e7a7edf33eef7c257781d7b418dd70f8710aab71f51f140b809620cd). No history, reflog, archived worktree, signed app or release archive was deleted. Space was reclaimed only from regenerable Xcode ModuleCache.noindex, Index.noindex, Build/Intermediates.noindex and SourcePackages directories under three old .release build caches. The signed products and source remain intact. No user data, notes, credentials or security settings were changed.

Build 346 will be prepared from the shared source and verified before publication and installation. The earlier local overlay preview is not release evidence; all final layout and release checks must use the new complete generated artifact. Actual results, memory/disk measurements, publication and device outcomes are recorded in the final build-346 release report.
